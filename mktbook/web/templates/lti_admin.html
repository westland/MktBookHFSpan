Agregar Nuevo Registro LMS
Instrucciones de Canvas ↓
  1. Canvas Admin → Developer Keys → + LTI Key
  2. Método: Paste JSON → pega la URL {{ base_url }}/lti/config
  3. Anota el Client ID numérico que asigna Canvas
  4. Cambia la clave a ON
  5. Configuración del Curso → Apps → Add App → By Client ID
  6. Anota el Deployment ID que muestra Canvas después de instalar
  7. Llena el formulario a continuación con:
    • Issuer: https://canvas.instructure.com
    • Auth Login URL: https://canvas.instructure.com/api/lti/authorize_redirect
    • Auth Token URL: https://canvas.instructure.com/login/oauth2/token
    • JWKS URL: https://canvas.instructure.com/api/lti/security/jwks
Instrucciones de Blackboard / Ultra ↓
  1. Administrador de Blackboard → Proveedores de Herramientas LTI → Registrar Herramienta LTI 1.3
  2. Ingresa tu OIDC Login URL, Redirect URI y JWKS URL de arriba
  3. Blackboard generará un Client ID y un Deployment ID
  4. Llena el formulario a continuación con:
    • Issuer: https://blackboard.com
    • Auth Login URL: https://YOUR-BB-DOMAIN/api/v1/gateway/oidcauth
    • Auth Token URL: https://YOUR-BB-DOMAIN/api/v1/gateway/oauth2/jwttoken
    • JWKS URL: https://YOUR-BB-DOMAIN/api/v1/gateway/lti/public/publickey
